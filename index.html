式の読み方のルール
  • 手札は全部使います。並べた順番がそのまま式になります。
  • ( ) のカードで、計算する範囲を自分で決められます。√ ( 3 + 2 × √ 2 ) のように、ルートの中身もまとめられます（二重根号）。
  • 強い順：( ) → 関数（sin cos tan ln log log₂ √ |·|）と ! → ^ → C → × ÷ → + −。
  • 関数はすぐ右の1項だけにかかります。√ 4 + 5 は √4 + 5、√ ( 4 + 5 ) は √9。
  • ^ は右から計算します（2 ^ 3 ^ 2 = 2⁹）。
  • ! は階乗（3 ! = 6）。C は組み合わせ（5 C 2 = ₅C₂ = 10）。
  • 数字はくっつきません（1 2 は 12 になりません）。2π のような省略したかけ算もできません。必ず × を使います。
  • − は引き算だけです。式の先頭や記号の直後には置けません。
  • log は常用対数（底10）、log₂ は底2、|·| は絶対値です。
  • 封印数は整数のほか、分数・π・√（二重根号の形のことも）・e を含むことがあります。
  • どの問題も、正解になる式は1つだけです（足し算・かけ算の順番の入れ替えや、意味の変わらないかっこの付け方の違いは同じ式とみなします）。
